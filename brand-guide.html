CSS Implementation Examples

Base Hero Navigation Bar

.hero-nav {
  background: linear-gradient(90deg, #000000 0%, #0F172A 100%);
  border-bottom: 2px solid #81D8D0;
  padding: 20px 40px;
  display: flex;
  justify-content: space-between;
  align-items: center;
  box-shadow: 0 10px 30px rgba(0, 0, 0, 0.5);
}
Key Features: The gradient background sweeps from pure black (#000000) on the left to deep navy (#0F172A) on the right. The 2px Tiffany bottom border provides a premium accent line that separates the navigation from page content. Box shadow adds depth.

Logo Styling (Image-Based)

.hero-nav .logo {
  height: 50px;    /* Match or exceed CTA button height */
  width: auto;
  display: block;
  cursor: pointer;
}
Sizing Rule: The logo height (50px) should match or exceed the "Get Started" CTA button's rendered height (~48px) for proper brand hierarchy. The logo is the dominant brand element and must command visual authority in the navigation bar. Use width: auto to maintain aspect ratio.

Logo Hover State (Tiffany Turquoise Tint)

.hero-nav .logo {
  transition: filter 0.3s ease;
  cursor: pointer;
}

.hero-nav .logo:hover {
  /* CSS filter to tint white PNG → Tiffany Turquoise #81D8D0 */
  filter: brightness(0) saturate(100%)
          invert(84%) sepia(14%) saturate(748%)
          hue-rotate(126deg) brightness(96%)
          contrast(86%);
}
Image Logo Hover: Since the logo is an image (not text), we use CSS filter to recolor the white PNG to Tiffany Turquoise (#81D8D0) on hover. The filter chain works by first converting to black (brightness(0)), then inverting and shifting hue to match the target color. This creates visual consistency with the nav link hover state. The 0.3s ease transition provides a smooth color shift. Alternative: Use a separate Tiffany-colored logo SVG and swap on hover with CSS content or JavaScript src swap for pixel-perfect accuracy.

Navigation Links - Default & Hover States

.hero-nav a {
  color: #FFFFFF;
  text-decoration: none;
  font-weight: 500;
  transition: color 0.3s ease;
}

.hero-nav a:hover {
  color: #81D8D0;
}
Hover Behavior: Links transition smoothly from white to Tiffany Turquoise in 0.3s. This provides clear visual feedback without jarring color shifts. The transition timing is fast enough to feel responsive but slow enough to appear intentional.

Active Page Indicator

.hero-nav a.active {
  color: #FFFFFF;
  border-bottom: 3px solid #81D8D0;
  padding-bottom: 5px;
}
Active Indicator: The 3px underline clearly shows which page the user is currently viewing. The white text remains unchanged (avoiding hover color) so users know the difference between "active current page" and "clickable hover state". The underline uses the same Tiffany color to maintain brand consistency.

CTA Button with Lift & Glow Effect

.hero-nav .cta-button {
  background: #81D8D0;
  color: #000000;
  border: none;
  padding: 12px 28px;
  border-radius: 6px;
  font-weight: 600;
  cursor: pointer;
  transition: all 0.3s ease;
  box-shadow: 0 2px 8px rgba(129, 216, 208, 0.3);

.hero-nav .cta-button:hover {
  transform: translateY(-2px);
  box-shadow: 0 6px 16px rgba(129, 216, 208, 0.5);

Interactive Effects: The button lifts up (-2px) when hovered and glows with an expanded shadow. The shadow color uses transparent Tiffany (#81D8D0) to create a cohesive visual effect. All transitions use 0.3s timing for smooth, professional motion.

Accessibility & Contrast Compliance

✅ WCAG AAA Compliance
  • Logo (#FFF on #000): 21:1 — Exceeds AAA
  • Nav text (#FFF on gradient): 6:1+ — Meets AA
  • Button (#81D8D0 on nav): 7.5:1 — Exceeds AA
  • Button text (#000 on #81D8D0): 13:1 — AAA+
❌ Avoid These Colors
  • Gray text on gradient (poor contrast)
  • Silver logo on black (insufficient contrast)
  • Light blue on dark gradient (too subtle)
  • Dark borders on dark bg (invisible)

📐 Logo Sizing Guidelines

Consistent logo sizing across all touchpoints reinforces brand recognition. The logo must always maintain its aspect ratio — only set height and use width: auto.

🔑 Golden Rule

The logo must always be at least as tall as the primary CTA button in any layout. The logo represents brand authority and should never be visually subordinate to action elements.

CSS Implementation

/* Logo sizing by context */
.logo-hero-nav    { height: 50px;  width: auto; }  /* 40-60px */
.logo-sticky-nav  { height: 50px;  width: auto; }  /* 40-60px  */
.logo-footer      { height: 45px;  width: auto; }  /* 40-50px  */
.logo-standalone  { height: 160px; width: auto; }  /* 120-200px */
.logo-email-sig   { height: 35px;  width: auto; }  /* 30-40px  */
.logo-email-header{ height: 60px;  width: auto; }  /* 50-80px  */

/* Scroll transition (hero → sticky) */
.hero-nav .logo {
  height: 50px;
  transition: height 0.3s ease;
}
.hero-nav.scrolled .logo {
  height: 50px;
}
Always use width: auto to preserve the logo's original aspect ratio. Never set both width and height simultaneously, as this will distort the logo.

Do's and Don'ts

✅ Do

  • Set height only, let width auto-scale
  • Keep logo ≥ CTA button height in navigation
  • Use SVG for scalable contexts (hero, print)
  • Maintain clear space equal to logo height / 4
  • Animate size transitions when scrolling
  • Use the 50px hero nav size as the default

❌ Don't

  • Set both width AND height (causes distortion)
  • Make the logo smaller than the CTA button
  • Use logos below 16px height (illegible)
  • Scale up raster logos beyond 2x original size
  • Remove clear space around the logo
  • Use the standalone size (160px) in navigation

Color Contrast Rules

On Dark Gradients
• Text: #FAFAFA (Off-White)
• Accents: #81D8D0 (Tiffany)
• Logo: White version
• Icons: #E5E7EB or #81D8D0
On Light Gradients
• Text: #0F172A (Deep Navy)
• Accents: #10B981 (Emerald)
• Logo: Black version
• Icons: #374151 or #10B981
On Turquoise/Green
• Text: #000000 (Pure Black)
• Never use white text
• Icons: #000000 or #0F172A
• Maximum contrast priority

Gradient Angle Reference

• 135deg – Diagonal top-left to bottom-right (most common, creates depth)
• 45deg – Diagonal bottom-left to top-right (gentler, more subtle)
• 90deg – Horizontal left to right (accent bars, horizontal elements)
• 180deg – Vertical top to bottom (long sections, natural reading flow)
• radial-gradient – Center-focused (spotlight effect, draw attention)

Performance & Best Practices

✅ DO: Use CSS gradients for backgrounds (no HTTP requests, better performance)
✅ DO: Test gradients on actual content and imagery before deploying
✅ DO: Ensure WCAG AA contrast ratios (4.5:1 for body text, 3:1 for large text)
✅ DO: Layer gradients sparingly for visual hierarchy
❌ DON'T: Use gradient images when CSS works (slower loading, less flexible)
❌ DON'T: Stack too many gradients on a single page (visual fatigue)
❌ DON'T: Use off-brand colors even if "they look good" (brand consistency is paramount)

Flow Wiring (Redirect Chain)

How each step redirects to the next. The OTO funnel chains immediately after purchase; the Standard funnel runs via email / retargeting with no post-purchase chaining.

OTO Funnel — immediate post-purchase

/ai-business-strike-team
   → (email nurture) →
/business-launchpad-oto
   purchase $37 →
/builders-club-6-month-oto
   YES → /welcome
   NO  → /builders-club-3-month-oto
      YES → /welcome
      NO  → /builders-club-trial-oto
         YES → /welcome
         NO  → /thank-you
               (→ Standard Recovery email, Day 5)

Standard Recovery — email / retargeting

/business-launchpad  ($97 purchase)
   → /thank-you

Email / retargeting offers
(higher price, no chaining):
  /builders-club-6-month   ($397)
  /builders-club-3-month   ($277)
  /builders-club-trial     ($1 → $97/mo)
     → each purchase → /welcome
Why only 2 thank-you pages? The master doc lists 5 buyer "variants" (OTO1 buyer, OTO2 buyer, Trial buyer, Launchpad-only, Standard buyer). These map onto the 2 physical pages above — GHL serves buyer-specific content dynamically by purchase tag or a ?tier= query param, so you don't need 5 separate URLs.

Notes for the Funnel Builder

  • Lowercase, hyphenated slugs only. No dates or random suffixes (replaces the old /testing-vsl-offer-page-new-5th-sep-1656 style auto-slugs).
  • Reserve -oto for Founder's-Deal versions only, so tracking & attribution stay clean.
  • OTO pages: post-purchase flow only. Set noindex and no direct navigation, so the discount stays private.
  • Standard (base) pages are public. These are the retargeting / indexable URLs.

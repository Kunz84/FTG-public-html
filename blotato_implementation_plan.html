Implementation
5 Phases to Full Loop

Start manual. Build confidence. Then automate. Each phase stands on its own.

1
Foundation Setup Week 1

Build the infrastructure before a single post goes out. Airtable becomes your data hub, Claude becomes your publishing interface.

Create Airtable base "Social Content Hub" with Posts table (full schema below)
Verify Blotato paid subscription is active (required for MCP access)
Connect all 9 social platforms to Blotato
Generate Blotato API key: Settings → API
Connect Claude to Blotato MCP: Customize → Connectors → https://mcp.blotato.com/mcp
Test: Ask Claude "List my Blotato accounts" to confirm connection
Define your UTM naming convention (source / medium / campaign)
2
Manual Publishing Workflow Week 1–2

Prompt Claude to create content and publish via Blotato. Manually log posts into Airtable. Learn the flow before automating it.

Prompt Claude with campaign name, UTM params, destination URL, and platform targets
Claude generates platform-native copy, constructs UTM URLs, calls blotato_post_create
Claude returns Post IDs and confirmation for each platform
Manually create Airtable record: Post ID, copy, image URL, UTM params, publish date
Set record Status = "Published"
3
Analytics Feedback Week 2–3

48 hours after publishing, pull performance data from Blotato and update Airtable. Airtable auto-calculates engagement rates and ranks.

Ask Claude: "What were the top performers from posts published on [DATE]?"
Claude queries Blotato API GET /posts/:id/analytics for each post
Update Airtable: Views, Likes, Comments, Reach fields for each record
Airtable formula auto-calculates Engagement Rate and Performance Rank
Add Iteration Notes: "This hook got 40% engagement — reuse pattern"
4
Learning Loop — Informed Content Week 3+

Before every new content batch, Claude analyzes your Airtable top performers and generates new posts based on proven patterns. The loop has begun.

Share top 5 Airtable posts (copy + metrics + notes) with Claude before generating
Claude identifies patterns: tone, length, hooks, topics, visuals, timing
Claude generates new posts using those patterns for the new campaign
Publish with UTM parameters → repeat the cycle
Each cycle: Airtable gets richer, Claude gets smarter, content gets better
5
n8n Automation (Optional) Week 4+

Once you understand the manual flow, offload the repetitive parts to n8n. Focus only on campaign strategy and content review.

n8n Workflow 1: Daily schedule → Blotato GET /published-posts → Create Airtable records
n8n Workflow 2: 48hrs after publish → Blotato GET /posts/:id/analytics → Update Airtable metrics
n8n uses Blotato verified community node (search "Blotato" in Community Nodes)
For self-hosted n8n: Set N8N_ENABLE_COMMUNITY_NODES=true and restart
Your role becomes: campaign planning → Claude prompt → review drafts → approve → monitor
Airtable Schema
Social Content Hub — Posts Table

Every field serves a purpose: some capture what was posted, some capture how it performed, some help Claude iterate.

Field Name Type Purpose
Post IDTextBlotato post ID — links record to Blotato API for analytics pull
StatusSelectDraft / Scheduled / Published / Analyzed
PlatformMulti-SelectX, Instagram, TikTok, LinkedIn, Facebook, YouTube, Threads, Bluesky, Pinterest
CopyLong TextFull post caption/text — reference for Claude to learn from
Image URLURLHosted image link — Airtable renders as thumbnail preview
Images (Attachments)AttachmentBackup copy of original image — survives if hosted URL expires
UTM SourceTexte.g., "social"
UTM MediumTexte.g., "instagram", "tiktok", "linkedin"
UTM CampaignTexte.g., "q4_launch", "product_awareness"
UTM ContentTextOptional: A/B variant identifier (e.g., "hook_v1" vs "hook_v2")
Full UTM URLFormulaAuto-constructs full tracking URL from UTM fields + base URL
Published DateDate/TimeWhen post went live — used for analytics scheduling (48hr window)
ViewsNumberFetched from Blotato API 48hrs post-publish
LikesNumberFetched from Blotato API
CommentsNumberFetched from Blotato API
ReachNumberFetched from Blotato API (note: LinkedIn excluded from analytics)
Engagement RateFormula(Likes + Comments) / Reach × 100 — primary performance metric
Performance RankFormulaRanks post vs. all others — surfaces top performers for Claude reference
Iteration NotesLong TextYour notes on what worked, what didn't — qualitative signal for Claude
